# 江苏省医师资格考试成绩统计技能

本仓库保存可复用的 **江苏省医师资格考试成绩统计** 技能安装包。

下载 `jiangsu-physician-exam-statistics.skill` 后，可在 Manus 中添加为自定义技能。安装包包括成绩统计流程、2026 年准考证与科目规则、年度考试基地分配，以及可生成标准统计工作簿的 Python 脚本。

该技能适用于已清洗的成绩单，支持按城市、科目代码、考试类别、考试基地与技能免考名单统计应考、实考、缺考、违纪、通过人数、通过率与均分。

## 2026 年主要口径

- 准考证第 3–4 位识别江苏省 13 个地级市；第 7–9 位识别科目代码。
- 分数为 0 且备注包含“违规”者认定为违纪；其余 0 分者认定为缺考。
- 实考等于应考减缺考，违纪不包含于缺考。
- 执业分数不低于 360 分、执助分数不低于 180 分者通过；缺考和违纪不计入通过人数。
- 2026 年乡村全科执业助理（216）统一归入南通市第一人民医院，公卫（130、230）统一归入江苏省疾控中心。

详细工作流、规则与脚本均包含在 `.skill` 安装包中。
